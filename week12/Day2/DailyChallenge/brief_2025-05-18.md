# Brief: multimodal large language models
_Generated: 2025-05-18_

## Summary

- Multimodal LLMs process text, images, audio, and video together, enabling richer AI understanding than text-only models. [1]
- GPT-4o, Gemini 1.5 Pro, and LLaVA are leading multimodal models; open-source options run locally via Ollama. [2]
- Key challenge is aligning representations across modalities — vision encoders (e.g. ViT) are fused with LLM token streams. [1]
- Benchmarks like MMMU and ScienceQA measure multimodal reasoning; top models now exceed 80 % on both. [3]
- Practical uses include document analysis, medical imaging, video captioning, and code generation from screenshots. [2][3]
